OVERVIEW:

This package contains everything needed to install the AutoNAV plugin into
Navisworks Manage 2024, 2025, 2026, or 2027. The installation is fully
automated and detects all installed versions at once.

================================================================================

FILE STRUCTURE:

AutoNAV-Installer-v3.0.0/

|   +-- Right-click -> Run as administrator

|   +-- Best for: All users
|
+-- Install-AutoNAV.ps1              [PowerShell Installer Script]
|   +-- Run from PowerShell as Administrator

INSTALL LOCATION (after successful installation):

For each Navisworks version found:

  C:\ProgramData\Autodesk\Navisworks Manage 2024\Plugins\AutoNAV\
    AutoNAV.dll
    AutoNAV.addin
    AutoNAV.pdb

  C:\ProgramData\Autodesk\Navisworks Manage 2025\Plugins\AutoNAV\
    AutoNAV.dll
    AutoNAV.addin
    AutoNAV.pdb

  (same pattern for 2026 and 2027)

IMPORTANT: Both AutoNAV.dll and AutoNAV.addin must always be in the same
AutoNAV\ subfolder. The .addin manifest references the DLL by relative path.

================================================================================

INSTALLATION SUMMARY:

The installer performs these steps automatically:

Step 1: Verify Administrator Privileges
Step 2: Find each installed version of Navisworks Manage (2024/2025/2026/2027)
Step 3: Create C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
Step 4: Verify all required source files are present
Step 5: Backup existing AutoNAV installation (if any)
Step 6: Close running Navisworks processes
Step 7: Copy AutoNAV.dll, AutoNAV.addin, AutoNAV.pdb to AutoNAV\ subfolder
Step 8: Report which versions were installed vs. skipped

================================================================================

MANUAL INSTALLATION:

To manually install for a specific version:

1. Create this folder (example for 2025):
   C:\ProgramData\Autodesk\Navisworks Manage 2025\Plugins\AutoNAV\

2. Copy into that AutoNAV\ subfolder:
   - AutoNAV.dll
   - AutoNAV.addin

3. Launch Navisworks Manage 2025
4. AutoNAV appears in the Add-Ins ribbon

Repeat for each Navisworks version you want to install to.

================================================================================

UNINSTALLATION:

Option 1 - PowerShell (cleans all versions):
  Run as Administrator: .\Install-AutoNAV.ps1 -Uninstall

Option 2 - Manual (one version at a time):
  Delete the AutoNAV\ subfolder from:
  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
