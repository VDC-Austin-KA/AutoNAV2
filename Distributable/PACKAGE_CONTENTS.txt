INSTALLATION SUMMARY:

The installer performs these steps automatically:

Step 1: Verify Administrator Privileges
   → Ensures user has required permissions

Step 2: Locate Navisworks Installation
   → Searches for Navisworks 2025 or 2024
   → Checks standard installation paths
   
Step 3: Create/Verify AddIns Directory
   → Creates folder if it doesn't exist
   → Sets proper permissions

Step 4: Verify Installation Files
   → Checks all required files are present
   → Reports if any files are missing

Step 5: Backup Existing Installation (if needed)
   → Creates timestamped backup folder
   → Preserves previous version

Step 6: Close Running Navisworks
   → Gently closes Navisworks if running
   → Prevents file locking issues

Step 7: Copy Plugin Files
   → AutoNAV.dll → AddIns folder
   → AutoNAV.addin → AddIns folder
   → AutoNAV.pdb → AddIns folder (if present)

Step 8: Verify Installation
   → Confirms files are in correct location
   → Reports success or failure

Step 9: Display Success Message
   → Shows installation completion
   → Provides next steps

================================================================================

POST-INSTALLATION:

After successful installation:

1. AutoNAV files are located at:
   C:\Program Files\Autodesk\Navisworks Manage 2025\AddIns\

2. Navisworks will automatically load AutoNAV on next launch

3. Users will see AutoNAV in the "Add-Ins" ribbon tab

4. Click AutoNAV button to open the plugin interface

SYSTEM REQUIREMENTS VERIFICATION:

Before running installer, verify:

✓ Windows 10 or Windows 11 (32-bit or 64-bit Windows, 64-bit app)
✓ Navisworks Manage 2025 or 2024 installed
✓ .NET Framework 4.8 or later installed
✓ Administrator account or UAC privileges
✓ At least 500 MB free disk space
✓ Internet connection (optional, for downloading .NET if needed)

To check .NET Framework version:
1. Open Control Panel
2. Go to Programs > Programs and Features
3. Look for ".NET Framework 4.8" in the list

To check Windows version:
1. Press Windows Key + Pause/Break
2. Check "System" window for OS version

TROUBLESHOOTING QUICK REFERENCE:

Issue: "Administrator privileges required"
→ Right-click Install-AutoNAV.bat, select "Run as administrator"

Issue: Navisworks not detected
→ Install Navisworks Manage 2025
→ Check installation path is standard

Issue: AutoNAV doesn't appear in Navisworks
→ Close Navisworks completely
→ Run installer again
→ Restart Navisworks

Issue: Permission denied errors
→ Close Navisworks completely
→ Run installer as Administrator
→ Disable antivirus temporarily
→ Check file permissions in AddIns folder

Issue: ".NET Framework 4.8 not found"
→ Download and install from:
   https://dotnet.microsoft.com/en-us/download/dotnet-framework

See INSTALLATION_GUIDE.md for more detailed troubleshooting.

================================================================================

UNINSTALLATION:

To uninstall AutoNAV:

Option 1: Using PowerShell
   Open PowerShell as Administrator
   Navigate to installer folder
   Run: .\Install-AutoNAV.ps1 -Uninstall

Option 2: Manual
   Close Navisworks completely
   Delete from: C:\Program Files\Autodesk\Navisworks Manage 2025\AddIns\
   - AutoNAV.dll
   - AutoNAV.addin
   - AutoNAV.pdb

Option 3: Restore Backup
   If a backup was created:
   - Navigate to AutoNAV_Backup_[timestamp] folder in AddIns
   - Copy files back to parent AddIns folder
   - Overwrite when prompted
