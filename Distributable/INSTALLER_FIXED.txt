HOW YOUR COWORKERS USE IT:

OPTION 1: BATCH FILE (Easiest - Recommended)
  1. Right-click Install-AutoNAV.bat
  2. Select "Run as administrator"
  3. Wait 10-20 seconds
  4. See summary of which Navisworks versions were installed
  5. Restart Navisworks
  6. AutoNAV appears in Add-Ins tab

OPTION 2: POWERSHELL (Advanced Users)
  1. Open PowerShell as Administrator
  2. Navigate to installer folder
  3. Run: .\Install-AutoNAV.ps1
  4. Wait for completion
  5. Restart Navisworks

OPTION 3: SILENT MODE (IT Deployment)
  1. Open PowerShell as Administrator
  2. Run: .\Install-AutoNAV.ps1 -Silent
  3. Installation runs without prompts
  4. Suitable for Group Policy deployment
