INSTALLATION INSTRUCTIONS
================================================================================

METHOD 1: AUTOMATED INSTALLATION (Recommended)
───────────────────────────────────────────
Prerequisites:
  - Extract AutoNAV_v3.0.0.zip
  - Close all Navisworks instances
  - Have administrator privileges

Steps:
  1. Navigate to extracted folder
  2. Right-click Install_AutoNAV.bat
  3. Select "Run as administrator"
  4. Read the installer messages
  5. Wait for completion message
  6. Close the installer window
  7. Restart Navisworks Manage
  8. Verify in Add-ins menu

Time: 2-3 minutes

METHOD 2: MANUAL INSTALLATION
─────────────────────────────
Prerequisites:
  - Extract AutoNAV_v3.0.0.zip
  - Administrator privileges
  - Know your Navisworks version

Steps:
  1. Identify your Navisworks Plugins folder:
     For 2025: C:\ProgramData\Autodesk\Navisworks Manage 2025\Plugins
     For 2024: C:\ProgramData\Autodesk\Navisworks Manage 2024\Plugins
  
  2. Copy these files from Plugin subfolder:
     - AutoNAV.dll
     - AutoNAV.addin
  
  3. Paste into your Plugins folder
  4. Close and restart Navisworks
  5. Verify in Add-ins menu

Time: 5 minutes

METHOD 3: USER-LEVEL INSTALLATION (No Admin)
──────────────────────────────────────────
Prerequisites:
  - Extract AutoNAV_v3.0.0.zip
  - Know your user profile folder

Steps:
  1. Copy Plugin folder files
  2. Paste to: %APPDATA%\Autodesk\Navisworks Manage\Plugins\
  3. Close and restart Navisworks
  4. Verify in Add-ins menu

Time: 5 minutes
Note: Only affects current user

================================================================================
TROUBLESHOOTING
================================================================================

Plugin Not Appearing:
  - Check that files are in correct Plugins folder
  - Verify .NET Framework 4.8 is installed
  - Restart Navisworks
  - Check Windows Event Viewer for errors

Installation Failed:
  - Ensure running as Administrator
  - Verify Navisworks is not running
  - Check that files are not read-only
  - Try manual installation method

Plugin Crashes:
  - Verify correct Navisworks version
  - Check that .NET 4.8 is installed
  - Restart Navisworks
  - Reinstall the plugin

Functions Not Working:
  - Ensure Navisworks file has search sets
  - Check that multi-discipline content exists
  - Review FEATURE_GUIDE.txt
  - Verify function prerequisites

Performance Issues:
  - Close other applications
  - Use subset of model for testing
  - Run batch operations (Function 6) during off-hours
  - Check available disk space
