================================================================================
QUICK START GUIDE
================================================================================

FOR END USERS (Distributable\ root):
  1. Right-click Install-AutoNAV.bat
  2. Select "Run as administrator"
  3. Installer installs to all Navisworks versions found
  4. Restart Navisworks Manage
  5. Access plugin from Add-ins menu

FOR END USERS (AutoNAV_v3.0.0\ folder):
  1. Right-click Install_AutoNAV.bat
  2. Select "Run as administrator"
  3. Follow prompts
  4. Restart Navisworks Manage
  5. Access plugin from Add-ins menu

FOR ADMINISTRATORS (Manual):
  1. Create: C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
  2. Copy AutoNAV.dll and AutoNAV.addin into that AutoNAV\ subfolder
  3. Restart Navisworks

FOR DEVELOPERS:
  1. Source code: C:\Users\kacker\source\Repos\AutoNAV\AutoNAV\
  2. Build output: ...\bin\Release\ (AutoNAV.dll, .pdb)
  3. Project: AutoNAV.csproj
