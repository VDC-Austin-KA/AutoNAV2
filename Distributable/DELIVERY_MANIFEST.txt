Supported Installation Methods:

1. EASIEST - Batch File Launcher (Recommended)
   File: Install-AutoNAV.bat
   Method: Right-click -> Run as administrator
   Time: 10-20 seconds
   Best for: All users

2. SCRIPTED - PowerShell Installation
   File: Install-AutoNAV.ps1
   Method: Run from PowerShell as Administrator
   Options: -Silent, -Uninstall
   Best for: Advanced users, batch deployments

3. MANUAL - File Copy Method
   Create: C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
   Copy: AutoNAV.dll and AutoNAV.addin (both into that AutoNAV\ subfolder)
   Repeat for each Navisworks version installed
   Best for: Advanced users, troubleshooting

DEPLOYMENT INSTRUCTIONS:

For End Users:
  1. Extract installer package
  2. Right-click Install-AutoNAV.bat
  3. Select "Run as administrator"
  4. Restart Navisworks
  5. AutoNAV appears in Add-Ins tab

For IT Administrators:
  1. Test on pilot machine
  2. Verify functionality
  3. Deploy to network share or use Group Policy
  Silent deployment: powershell.exe -NoProfile -ExecutionPolicy Bypass ^
    -Command "& 'path\to\Install-AutoNAV.ps1' -Silent"
