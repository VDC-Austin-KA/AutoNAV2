WHAT'S NEW IN v3.0.0:

+ Full support for Navisworks Manage 2024, 2025, 2026, and 2027
+ Single installer detects and installs to all versions simultaneously
+ Correct plugin path: C:\ProgramData\...\Plugins\AutoNAV\ (per Navisworks spec)
+ PowerShell-based installation engine with error handling
+ Batch file launcher for ease of use
+ Automatic Navisworks process management (closes before installing)
+ Backup/restore functionality (timestamped backup on upgrade)
+ Silent installation mode (-Silent flag)
+ Uninstall support (-Uninstall flag, removes from all versions)
+ Colorized installer output
+ Comprehensive documentation package

Minimum:
- Windows 10 (Build 19041) or Windows 11

- Navisworks Manage 2025 or 2026

- SSD storage

================================================================================

PLUGIN INSTALLATION PATH:

AutoNAV installs to the correct Navisworks third-party plugin location:

  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\

Both AutoNAV.dll and AutoNAV.addin are placed in the same AutoNAV\ subfolder.
Navisworks discovers the plugin from this path consistently across all versions.

================================================================================

KNOWN ISSUES:

None reported in this release.

If you encounter issues:
1. Check INSTALLATION_GUIDE.md troubleshooting section
2. Verify system requirements are met
3. Ensure both AutoNAV.dll and AutoNAV.addin are in the same AutoNAV\ subfolder
4. Ensure .NET Framework 4.8 is installed

================================================================================

UPGRADE PATH:

FROM ANY PREVIOUS VERSION:

The installer automatically:
1. Detects previous installation
2. Creates timestamped backup in the same AutoNAV\ folder
3. Installs new version
4. Verifies installation

No additional steps needed. Simply run the installer.

Backup location:
  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
    Backup_YYYYMMDD_HHMMSS\
      AutoNAV.dll
      AutoNAV.addin

================================================================================

SILENT DEPLOYMENT:

For IT administrators:

  powershell.exe -NoProfile -ExecutionPolicy Bypass `
    -File "path\to\Install-AutoNAV.ps1" -Silent

Installs to all Navisworks versions found, no prompts.
