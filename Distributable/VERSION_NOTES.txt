UPGRADE PATH:

FROM v2.x TO v3.0.0:

The installer automatically:
1. Detects previous installation
2. Creates timestamped backup
3. Preserves user settings (if applicable)
4. Installs new version
5. Verifies installation

No additional steps needed. Simply run the installer.

Backup location:
C:\Program Files\Autodesk\Navisworks Manage 2025\AddIns\
  └── AutoNAV_Backup_[YYYYMMDD_HHMMSS]\

DEPLOYMENT INFORMATION:

For IT Administrators:

Silent Installation:
powershell.exe -NoProfile -ExecutionPolicy Bypass ^
  -Command "& 'path\to\Install-AutoNAV.ps1' -Silent"

Group Policy Deployment:
Can be deployed via Group Policy startup scripts

Network Deployment:
Place installer on network share and run from there

License Considerations:
AutoNAV is provided as-is for internal use
Each user needs their own Navisworks license

MIGRATION NOTES:

If upgrading from previous version:

1. Old version backup is created automatically
2. Settings are preserved (plugin-dependent)
3. Restart Navisworks after upgrade
4. Check ribbon UI for AutoNAV button

To revert to previous version:
1. Close Navisworks
2. Copy files from AutoNAV_Backup_[timestamp] folder
3. Overwrite current installation
4. Restart Navisworks
