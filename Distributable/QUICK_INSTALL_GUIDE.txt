================================================================================
                        QUICK INSTALL GUIDE
                            60 Second Summary
================================================================================

WHAT TO DO RIGHT NOW:

1. Right-click "Install-AutoNAV.bat"
2. Select "Run as administrator"
3. Wait 10-20 seconds
4. Installer installs to all Navisworks versions found (2024/2025/2026/2027)
5. Restart Navisworks
6. Done! AutoNAV will appear in the Add-Ins tab

================================================================================

WHAT IF SOMETHING GOES WRONG?

Issue: "Administrator privileges required"
-> Right-click file, select "Run as administrator"

Issue: "No compatible Navisworks installation found"
-> Install Navisworks Manage 2024, 2025, 2026, or 2027 first

Issue: AutoNAV doesn't appear
-> Close Navisworks completely, run installer again, restart Navisworks

For more help: Open README.txt

================================================================================

WHAT GETS INSTALLED (per Navisworks version):

- AutoNAV.dll   (the plugin)
- AutoNAV.addin (plugin configuration)
- AutoNAV.pdb   (debug info)

Install location for each version:
  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
