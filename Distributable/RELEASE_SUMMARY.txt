================================================================================
FEATURES INCLUDED
================================================================================

Function 1: Discipline Search Sets
  Creates hierarchical search sets organized by discipline

Function 2: Element Property Search Sets
  Generates search sets based on element properties and categories

Function 3: Custom Value-Based Search Sets
  Creates search sets from any property value in the model

Function 4: Automated Clash Test Generation
  Generates clash tests from discipline search set combinations

Function 5: Clash Result Grouping
  Intelligently groups clash results by discipline and category

Function 6: Walls/Floors Clash Grouping by Discipline
  Groups clash results into Walls and Floors groups scoped per discipline pair

INSTALLATION OPTIONS
================================================================================

Option 1: AUTOMATED INSTALLATION (Recommended)
  1. Extract AutoNAV_v3.0.0.zip
  2. Right-click Install_AutoNAV.bat -> Run as administrator
  3. Installs to all found Navisworks versions (2024-2027)
  4. Restart Navisworks
  Estimated time: 2-3 minutes

Option 2: MANUAL INSTALLATION
  For each version installed, create:
  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
  Copy AutoNAV.dll and AutoNAV.addin into that AutoNAV\ subfolder.
