QUICK START
-----------
1. Install AutoNAV using Install_AutoNAV.bat
2. Restart Navisworks Manage
3. Open your Navisworks file
4. Go to Add-ins → AutoNAV
5. Use the tabbed interface to access features

================================================================================
FUNCTION 1: CREATE DISCIPLINE SEARCH SETS
================================================================================

Purpose: Organizes model content by discipline
Creates a standardized folder structure with search sets for:
  - ARCH (Architecture)
  - STRC (Structural)
  - MECH (Mechanical)
  - PLBG (Plumbing)

How to Use:
1. Go to "Search Sets (Func 1-3)" tab
2. Click "Generate Discipline Sets"
3. AutoNAV creates the "1. DISCIPLINES" folder with discipline-specific sets
4. Each search set contains all items from that discipline

Result: Organized hierarchy for multi-discipline coordination

================================================================================
FUNCTION 2: CREATE ELEMENT PROPERTY SEARCH SETS
================================================================================

Purpose: Creates search sets based on element properties
Useful for organizing by category, type, or other properties

How to Use:
1. Go to "Search Sets (Func 1-3)" tab
2. Select disciplines using checkboxes
3. Choose a property type from the dropdown
4. Click "Generate Element Property Search Sets"
5. Creates hierarchical sets: Discipline → Property Category → Property Values

Options:
  - Select All: Check all disciplines
  - Deselect All: Uncheck all disciplines
  - Invert Selection: Toggle checked/unchecked
  - Refresh: Reload discipline list

Result: Property-organized search sets for detailed filtering

================================================================================
FUNCTION 3: CREATE CUSTOM VALUE-BASED SEARCH SETS
================================================================================

Purpose: Generates search sets from unique property values
Useful for creating project-specific organization schemes

How to Use:
1. Go to "Search Sets (Func 1-3)" tab
2. Select a discipline from dropdown
3. Select property category
4. Select specific property
5. Click "Generate Custom Search Sets"
6. AutoNAV creates sets for each unique value

Benefits:
  - Customize organization to your project needs
  - Works with any property in your model
  - Create multiple times for different property types

Result: Custom-tailored search sets based on your data

================================================================================
FUNCTION 4: GENERATE CLASH TESTS
================================================================================

Purpose: Automates clash test creation from search sets
Reduces manual test setup and ensures consistency

How to Use:
1. Go to "Clash Tests (Func 4-6)" tab
2. Click "Generate Clash Tests"
3. Select discipline combinations to test
4. AutoNAV creates clash tests for each combination
5. Tests are automatically configured and ready to run

What It Does:
  - Combines discipline search sets to find conflicts
  - Creates named tests for tracking
  - Configures clash tolerance parameters
  - Prepares tests for batch execution

Result: Automated clash detection across disciplines

================================================================================
FUNCTION 5: GROUP CLASH RESULTS
================================================================================

Purpose: Organizes clash results by discipline and category
Makes reviewing large clash datasets manageable

How to Use:
1. Go to "Clash Tests (Func 4-6)" tab
2. Select a clash test from dropdown
3. Choose grouping mode:
   - By Discipline: Group clashes by involved disciplines
   - By Category: Group by element category
   - By Type: Group by element type
4. Choose sub-grouping if desired
5. Optionally check "Keep existing groups"
6. Click "Group Selected Test" or "Group All Tests"

Grouping Options:
  - Discipline-based (most common for multi-discipline)
  - Category-based (for property-driven analysis)
  - Type-based (for element classification)

Result: Organized clash results for efficient review

================================================================================
FUNCTION 6: BATCH UPDATE CLASH TESTS
================================================================================

Purpose: Updates multiple clash tests simultaneously
Saves time on test maintenance and configuration

How to Use:
1. Go to "Clash Tests (Func 4-6)" tab
2. Click "Update All Tests (Run Simultaneously)"
3. Selects all available clash tests
4. Updates them in parallel for faster processing
5. Reports progress and results

Benefits:
  - Much faster than updating tests individually
  - Ensures consistency across all tests
  - Frees up your time for analysis
  - Handles large numbers of tests efficiently

Result: All clash tests updated and ready for review

BEST PRACTICES
================================================================================

1. DATA PREPARATION
   - Ensure all disciplines are properly tagged in Navisworks
   - Use consistent naming conventions
   - Clean up unnecessary geometry before analysis

2. SEARCH SET ORGANIZATION
   - Start with Function 1 (discipline sets) as foundation
   - Use Function 2 for property-based refinement
   - Leverage Function 3 for project-specific customization

3. CLASH TEST MANAGEMENT
   - Use Function 4 to automate test generation
   - Keep clash test naming consistent
   - Use Function 6 for regular batch updates

4. RESULT REVIEW
   - Use Function 5 to organize results logically
   - Group by discipline for multi-discipline projects
   - Export organized results for stakeholder review

5. WORKFLOW OPTIMIZATION
   - Save time-consuming searches as smart folders
   - Create reusable search set templates
   - Use batch operations (Function 6) for efficiency

PERFORMANCE TIPS
================================================================================

For Large Models (>1GB):
  - Use disciplined search sets rather than full model checks
  - Run Function 6 updates during off-hours
  - Consider splitting work by discipline

For Complex Geometries:
  - Use Property-based search sets (Function 2) for faster processing
  - Run clash tests on subsets rather than full model
  - Use Function 5 grouping to focus on specific areas

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Functions not working as expected
Solution: Ensure your Navisworks file has:
  - Multiple disciplines/models
  - Proper search sets or properties
  - Clash tests configured

Issue: Slow performance
Solution:
  - Close other applications to free RAM
  - Reduce model size by filtering before use
  - Run batch operations during off-hours

Issue: Search sets not appearing
Solution:
  - Check that Function 1 was completed first
  - Verify disciplines are properly tagged in model
  - Refresh the search set list
