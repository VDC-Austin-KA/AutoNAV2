THE BASICS:

What is AutoNAV?
  AutoNAV is a plugin for Navisworks Manage that provides automated design
  coordination and clash detection features. Once installed, it appears as a
  button in Navisworks' "Add-Ins" ribbon tab.

What does the installer do?
  - Detects all installed versions of Navisworks Manage (2024, 2025, 2026, 2027)
  - Installs AutoNAV to each version found simultaneously
  - Creates the plugin folder if it doesn't exist
  - Backs up any existing installation
  - Takes about 10-20 seconds

What happens after installation?
  - Next time you open any installed Navisworks version, AutoNAV will be available
  - Click the AutoNAV button in the Add-Ins tab to use it
  - That's it! No additional setup needed.

INSTALLATION STEPS (In Detail):

1. Right-click "Install-AutoNAV.bat"
   The file is in this same folder

2. Select "Run as administrator"
   Click YES if Windows asks "Allow this app to make changes?"

3. A window will open and show progress for each Navisworks version found:
   - Checking for Administrator privileges
   - Looking for installed Navisworks versions
   - Creating Plugins\AutoNAV\ folder (if needed)
   - Backing up old version (if you have one)
   - Copying files

4. Wait for the summary showing which versions were installed.

5. Close the window and restart Navisworks
   AutoNAV will appear in the Add-Ins tab

6. Click the AutoNAV button to start using it

================================================================================

WHERE FILES GET INSTALLED:

For each Navisworks version found on your machine:
  C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
    AutoNAV.dll     (the plugin)
    AutoNAV.addin   (configuration)

WHAT IF I SEE AN ERROR?

"Administrator privileges required"
  -> Right-click the file and select "Run as administrator"

"No compatible Navisworks installation found"
  -> Install Navisworks Manage 2024, 2025, 2026, or 2027 first

"AutoNAV doesn't appear in Navisworks"
  -> Close Navisworks completely (not just the window)
  -> Run the installer again
  -> Restart Navisworks

"Something else went wrong"
  -> Read the error message carefully
  -> See README.txt for detailed troubleshooting
  -> See INSTALLATION_GUIDE.md for comprehensive help
