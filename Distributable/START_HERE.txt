THE BASICS:

What is AutoNAV?
  AutoNAV is a plugin for Navisworks Manage that provides automated design
  coordination and clash detection features. Once installed, it appears as a
  button in Navisworks' "Add-Ins" ribbon tab.

What does the installer do?
  - Detects your Navisworks installation
  - Backs up any existing installation
  - Copies necessary files to the correct location
  - Verifies everything is working
  - Takes about 10-20 seconds

What happens after installation?
  - Next time you open Navisworks, AutoNAV will be available
  - Click the AutoNAV button in the Add-Ins tab to use it
  - That's it! No additional setup needed.

How long does it take?
  - Installation: 10-20 seconds
  - To be ready to use: About 2 minutes (time to open Navisworks)

INSTALLATION STEPS (In Detail):

1. Right-click "Install-AutoNAV.bat"
   └─ The file is in this same folder

2. Select "Run as administrator"
   └─ Click YES if Windows asks "Allow this app to make changes?"

3. A window will open and show:
   └─ Checking for Administrator privileges
   └─ Looking for Navisworks
   └─ Creating AddIns folder (if needed)
   └─ Backing up old version (if you have one)
   └─ Copying files
   └─ Verifying installation

4. Wait for the message: "Installation Completed Successfully!"
   └─ This means it worked

5. Close the window and restart Navisworks
   └─ AutoNAV will appear in the Add-Ins tab

6. Click the AutoNAV button to start using it
   └─ Enjoy!

QUICK TROUBLESHOOTING:

Problem: "I can't find Install-AutoNAV.bat"
Solution: All files should be in the same folder. Make sure you extracted
          the ZIP file and all files are together.

Problem: "Administrator privileges required"
Solution: Right-click Install-AutoNAV.bat, select "Run as administrator"

Problem: "Permission denied" or "Access denied"
Solution: Close Navisworks completely, then try again as Administrator

Problem: "Navisworks not found"
Solution: Install Navisworks Manage 2025. Make sure you have "Manage"
          not "Simulate" or "Freedom"

Problem: AutoNAV button doesn't appear
Solution: Close Navisworks completely (not just the window)
          Restart Navisworks
          If still nothing, run the installer again

For more help: Read README.txt or INSTALLATION_GUIDE.md
