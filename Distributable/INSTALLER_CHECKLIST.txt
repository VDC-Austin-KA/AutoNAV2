================================================================================
                  AutoNAV v3.0.0 - Installation Checklist
================================================================================

INSTALLATION OPTIONS:

OPTION 1 - EASIEST (Recommended for all users):
  1. Right-click "Install-AutoNAV.bat"
  2. Select "Run as administrator"
  3. Installer auto-detects and installs to all Navisworks versions (2024-2027)
  4. Complete in 10-20 seconds

OPTION 2 - POWERSHELL (Advanced users):
  1. Open PowerShell as Administrator
  2. Navigate to installer folder
  3. Run: .\Install-AutoNAV.ps1
  4. Supports -Uninstall flag to remove from all versions

OPTION 3 - MANUAL (Advanced users):
  For each Navisworks version installed:
  1. Create: C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
  2. Copy AutoNAV.dll and AutoNAV.addin into that AutoNAV\ subfolder
  See INSTALLATION_GUIDE.md for details

================================================================================

WHAT THE INSTALLER DOES:

When you run the installer, it automatically:

1. Checks for Administrator privileges
2. Locates each installed version of Navisworks Manage (2024, 2025, 2026, 2027)
3. Creates C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\ if needed
4. Verifies all required files are present
5. Backs up any existing AutoNAV installation
6. Closes Navisworks if it's running
7. Copies AutoNAV.dll and AutoNAV.addin to the AutoNAV\ plugin subfolder
8. Reports which versions were installed successfully

Total time: 5-20 seconds depending on how many versions are found

SYSTEM REQUIREMENTS:

Required:
  [x] Windows 10 (Build 19041+) or Windows 11
  [x] Navisworks Manage 2024, 2025, 2026, or 2027
  [x] .NET Framework 4.8 or later
  [x] Administrator account access
  [x] ~10 MB free disk space per Navisworks version

NOT Supported:
  [ ] Navisworks Simulate (use Manage instead)
  [ ] Navisworks Freedom (use Manage instead)
  [ ] 32-bit systems (requires 64-bit)
  [ ] Navisworks 2023 or older
  [ ] Windows 7/8

INSTALLATION INSTRUCTIONS (Quick Summary):

STEP 1: Prepare
  1. Close Navisworks if running
  2. Ensure all installer files are together in one folder

STEP 2: Run Installer
  1. Right-click "Install-AutoNAV.bat"
  2. Select "Run as administrator"
  3. Click "Yes" when prompted for admin privileges

STEP 3: Wait for Completion
  1. Watch progress for each Navisworks version detected
  2. Review the summary showing installed vs. skipped versions

STEP 4: Verify Installation
  1. Launch Navisworks Manage
  2. Look for "Add-Ins" tab in ribbon menu
  3. Click "AutoNAV" button
  4. AutoNAV interface should open

TROUBLESHOOTING QUICK GUIDE:

PROBLEM: "Administrator privileges required"
SOLUTION: Right-click "Install-AutoNAV.bat", select "Run as administrator"

PROBLEM: "No compatible Navisworks installation found"
SOLUTION: Install Navisworks Manage 2024, 2025, 2026, or 2027 first

PROBLEM: "AutoNAV doesn't appear in Navisworks"
SOLUTION:
  - Close Navisworks completely
  - Run installer again as Administrator
  - Restart Navisworks and check Add-Ins tab

PROBLEM: Plugin fails to load
SOLUTION:
  - Verify both AutoNAV.dll and AutoNAV.addin are in the same AutoNAV\ subfolder:
    C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
  - Verify .NET Framework 4.8 is installed

For more help, see INSTALLATION_GUIDE.md

After successful installation, verify:

1. Files are in correct location for each version installed:
   [ ] C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\AutoNAV.dll
   [ ] C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\AutoNAV.addin

   [ ] Launch Navisworks
   [ ] Look for "Add-Ins" tab
   [ ] "AutoNAV" button is visible
   [ ] Click AutoNAV to open plugin

3. Plugin is functional:
   [ ] AutoNAV panel opens
   [ ] All UI elements appear
   [ ] Can interact with the interface
   [ ] No error messages in output

If all items checked, installation is successful!

UNINSTALLATION INSTRUCTIONS:

Method 1 - PowerShell (Recommended):
  1. Open PowerShell as Administrator
  2. Navigate to installer folder
  3. Run: .\Install-AutoNAV.ps1 -Uninstall
  4. Wait for completion

Method 2 - Manual:
  For each Navisworks version:
  1. Close Navisworks
  2. Delete:
     C:\ProgramData\Autodesk\Navisworks Manage 202X\Plugins\AutoNAV\
  3. Restart Navisworks
