WHAT THE INSTALLER DOES:

When you run the installer, it automatically:

1. ✓ Checks for Administrator privileges
2. ✓ Locates your Navisworks Manage installation
3. ✓ Creates AddIns folder if needed
4. ✓ Verifies all required files are present
5. ✓ Backs up any existing AutoNAV installation
6. ✓ Closes Navisworks if it's running
7. ✓ Copies plugin files to correct location
8. ✓ Verifies installation succeeded
9. ✓ Shows success message with next steps

Total time: 5-20 seconds depending on system

STEP 1: Prepare
  1. Close Navisworks if running

  1. Watch the installation progress
  2. Read the status messages
  3. Wait for "Installation Completed Successfully!" message

STEP 4: Verify Installation
  1. Launch Navisworks Manage 2025
  2. Look for "Add-Ins" tab in ribbon menu
  3. Click "AutoNAV" button

TROUBLESHOOTING QUICK GUIDE:

PROBLEM: "Administrator privileges required"
SOLUTION:
  - Right-click "Install-AutoNAV.bat"
  - Select "Run as administrator"
  - Click "Yes" when Windows asks

PROBLEM: "Navisworks not found"
SOLUTION:
  - Install Navisworks Manage 2025
  - Or verify installation is in standard location
  - Or use manual installation method

PROBLEM: "AutoNAV doesn't appear in Navisworks"
SOLUTION:
  - Close Navisworks completely (not just window)
  - Run installer again
  - Restart Navisworks
  - Check Add-Ins tab

PROBLEM: Installation failed with error
SOLUTION:
  - Read error message carefully
  - Close Navisworks completely
  - Disable antivirus temporarily
  - Run installer again as Administrator
  - See INSTALLATION_GUIDE.md for detailed troubleshooting

PROBLEM: ".NET Framework 4.8 not installed"
SOLUTION:
  - Download from: https://dotnet.microsoft.com/download/dotnet-framework
  - Install .NET Framework 4.8
  - Restart computer
  - Run installer again

For more help, see INSTALLATION_GUIDE.md

UNINSTALLATION INSTRUCTIONS:

To remove AutoNAV:

Method 1 - PowerShell (Recommended):
  1. Open PowerShell as Administrator
  2. Navigate to installer folder
  3. Run: .\Install-AutoNAV.ps1 -Uninstall
  4. Wait for completion

Method 2 - Manual:
  1. Close Navisworks
  2. Navigate to: C:\Program Files\Autodesk\Navisworks Manage 2025\AddIns\
  3. Delete:
     - AutoNAV.dll
     - AutoNAV.addin
     - AutoNAV.pdb (if present)
  4. Restart Navisworks

Method 3 - Restore Backup:
  1. Look for AutoNAV_Backup_[timestamp] folder in AddIns
  2. Copy files from backup folder
  3. Paste into parent AddIns folder
  4. Overwrite when prompted
  5. Restart Navisworks
